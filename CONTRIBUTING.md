# Contributing

This repository contains a SevenGen Studios community website demonstration.

## Workflow

1. Create a branch from `main`.
2. Make one focused change.
3. Run `npm ci` when dependencies are missing.
4. Run `npm run build`.
5. Open a pull request for review.
6. Merge only after the automated build check passes.

## Content rules

- Keep the disclaimer that this is not an official Waterhen Lake First Nation website.
- Treat community facts, department names, contact information, imagery and marks as subject to authorized verification.
- Do not publish personal, confidential or internal community information.
- Keep the SevenGen Studios attribution discreet and accurate.
